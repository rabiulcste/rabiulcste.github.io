TL;DR: One Flow Transformer is both the world model and the agent. The policy learns in imagination on the backbone's own features, trained online from scratch. Each imagined frame takes one denoising step, using 33× fewer FLOPs than prior diffusion agents.

I was happy to see DIAMOND show that diffusion models make excellent world models for online RL. But I think it gets the RL part a bit backward. The diffusion model is only a black-box simulator, and a separate policy network learns from its rollouts. I was heavily interested in one generative model for learning from experience. Dreamer seemed like the right idea, since its policy learns on the world model's own state. But Dreamer is recurrent and works in a mostly discrete latent space.

I wanted a cleaner, modern version of that idea, built on a diffusion transformer. In DRIFT, the RL agent sits directly on top of the Flow Transformer's backbone, the same network that imagines the world, and learns in its continuous latent space.

Making this work was harder than I expected. Reading out the control state from vanilla denoising features gave a bad policy, because those features are weak for control. So I borrowed an idea from self-supervised learning to explicitly shape predictive dynamics, which made the features much better. There were a few more things to take care of, like efficiency and stability, which you can read about in the paper. The first problem later led me to a super cool result in DEM.

Method

Imagination in one step per frame

Each clip shows the real game on the left and DRIFT imagining the same actions on the right, one denoising step per frame, from 8 real context frames taken mid-episode. For every environment the clip is the median of 10 rollouts by pixel error, so misses stay in. Frames are decoded for display.
