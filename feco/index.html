Abstract

REPA showed that generative models train better when their features are aligned with a pretrained DINOv2 encoder. We show that a flow map can supply this signal itself. The flow-map composition rule gives two views of one image, a noisier one and a cleaner one. An early block on the noisier view predicts the deeper features of the EMA model on the cleaner view. Each flow-map family already computes the cleaner view, so the teacher costs no extra forward pass. We add SIGReg, from LeJEPA, which shapes the predicted teacher-depth features toward an isotropic Gaussian. One setting works across MeanFlow, Shortcut Models and Lagrangian self-distillation, with no external encoder and no extra data. In a preliminary ImageNet-100 study, it lowers one-step FID in all three families.

Method

A flow map jumps from one point on the noise-to-data path to another. Its composition rule says that one long jump equals two shorter jumps in a row. So the model itself links the same image at two noise levels: a noisier point and a cleaner point. We use these as two views. A small predictor on an early block of the online model, run on the noisier view, predicts the features of a deeper block of the EMA model, run on the cleaner view. The target has a stop-gradient. This predictive loss is added to the usual flow-map loss.

The second term is SIGReg, from LeJEPA. It measures how far a batch of features is from an isotropic Gaussian, using random one-dimensional projections. We apply it to the predicted features at the teacher depth. Its role is to shape the distribution of these target features so they spread evenly across directions. It is one statistic on features the model already computes.

Why it is free

Each family already computes a point on the path that is cleaner than its input, as part of its own training target. That point is the teacher view.

FamilyTeacher viewExtra forward pass
Shortcut ModelsEMA half stepnone
MeanFlowtangent from its JVPnone
LSDlanding point of its target forwardnone

The remaining cost is the small predictor and the SIGReg statistic. No external encoder and no extra data are used.
