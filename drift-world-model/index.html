TL;DR: One Flow Transformer is both the world model and the agent. The policy learns in imagination on the backbone's own features, trained online from scratch. Each imagined frame takes one denoising step, using 33× fewer FLOPs than prior diffusion agents.

I was happy to see DIAMOND show that diffusion models make excellent world models for online RL. But I think it gets the RL part a bit backward. The diffusion model is only a black-box simulator, and a separate policy network learns from its rollouts. I was heavily interested in one generative model for learning from experience. Dreamer seemed like the right idea, since its policy learns on the world model's own state. But Dreamer is recurrent and works in a mostly discrete latent space.

I wanted a cleaner, modern version of that idea, built on a diffusion transformer. In DRIFT, the RL agent sits directly on top of the Flow Transformer's backbone, the same network that imagines the world, and learns in its continuous latent space.

Making this work was harder than I expected. Reading out the control state from vanilla denoising features gave a bad policy, because those features are weak for control. So I borrowed an idea from self-supervised learning to explicitly shape predictive dynamics, which made the features much better. There were a few more things to take care of, like efficiency and stability, which you can read about in the paper. The first problem later led me to a super cool result in DEM.

Imagination in one step per frame

DRIFT world model agent

One Flow Transformer learns the world from real experience, imagines new experience in one denoising step, and gives the actor and critic their state.

Self-supervised features shaped for control

Dreamer's state is trained to predict the future, so it is a natural state for control. A flow model is trained to denoise its input instead, and when trained online from scratch, its features alone make a poor state for the policy. DRIFT borrows the predictive idea of SPR. SPR matches encoders on augmented views, which do not fit noised latent inputs, so DRIFT trains the control state to predict the latent of the next real frame, given the action. On 8 Atari games, this raises the IQM human-normalized score from 0.20 to 0.79.

Tackling exposure bias in generation

A world model trained only on real frames first meets its own generations in imagination, where small errors pile up. This is exposure bias. Self Forcing reduces it in video generation by training on the model's own rollouts. An agent also needs reward and continuation heads that work on generated latents. So DRIFT generates a few latents from real context and trains on them in two ways. The heads learn to predict the real rewards and continuations there, and the backbone learns to denoise the next real latent with the generated ones as context. On all 26 Atari games, this raises the IQM from 0.45 to 0.67.

Results

On Atari 100k, DRIFT is competitive with DIAMOND, the closest prior diffusion world model. It has a higher IQM and median and a lower mean, while using 33× fewer FLOPs per imagined step. The paper has the full results on Atari, Craftium and Crafter, with all baselines and ablations.
